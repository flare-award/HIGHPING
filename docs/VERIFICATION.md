# Отчёт о проверке

Обновлено: 19 октября 2026 года.

## Выполнено

- Локально проверены синтаксические деревья C# и PowerShell, структура XML/YAML, соответствие имён WPF bindings; `git diff --check` проходит. Эти статические проверки не заменяют компиляцию или запуск.
- Успешный Windows Actions run [#39196080070](https://github.com/flare-award/HIGHPING/actions/runs/39196080070), commit `d87e175`, runner `windows-2022` (Windows Server 2022): restore, тесты и сборка solution, self-contained `win-x64` publish, загрузка и SHA-256 проверка официальных WinDivert 2.2.2 x64 DLL/SYS, лицензии и соответствующего исходного архива, подготовка notices, успешный smoke test запуска WPF-окна без включения задержки, создание portable ZIP и Inno Setup installer, загрузка артефактов.
- Smoke test запускает собранный exe, проверяет запись об успешном старте и отсутствие ошибок в журнале, затем закрывает процесс. Это не включает WinDivert capture и не проверяет фактическую задержку.
- Run содержит `LatencyStudio-Windows-x64` (установщик и portable ZIP, хранится 30 дней) и `LatencyStudio-Test-Results` (14 дней). Ссылки для скачивания: страница указанного run → **Artifacts**.

## Не проверено

| Сценарий | Статус | Ограничение |
|---|---|---|
| Запуск приложения на Windows 10/11 | Не проверено | CI выполнялся на Windows Server 2022; пользовательский интерфейс на Windows 10/11 вручную не запускался. |
| WinDivert: загрузка подписанного драйвера, захват, отложенная отправка и выключение на реальном трафике | Не проверено | Успешная сборка и проверка SHA-256 не проверяют поведение драйвера при выполнении. |
| Фактическая задержка TCP/UDP, IPv4/IPv6 и сопоставление измеренного RTT с настройкой | Не проверено | Не проводился сетевой интеграционный тест; target-режим опирается на калибровку TCP handshake и не обещает универсальный RTT для любого потока/узла. |
| UAC, tray, автозапуск, установка и удаление | Не проверено | Требуют ручного smoke-теста установленной сборки в Windows. |
| CS2, VALORANT, Discord, другие игры и античиты | Не проверено | Совместимость не заявляется и не гарантируется. |
| Принудительное завершение процесса и удерживаемые пакеты | Не проверено | При аварийном завершении часть пакетов в user-mode queue может потеряться; crash-proof delivery не обещается. |

Успешный CI run подтверждает сборку, тесты и упаковку на runner, но не является выпуском из тега, ручной проверкой установщика или доказательством корректной работы системного перехвата на компьютере пользователя. До Windows 10/11 runtime- и installer-smoke-test это остаётся открытым пунктом.
